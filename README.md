# traQuick

traQをより便利に使うためのChrome拡張機能です。

サイドバーへのカスタムリンク追加や、サービスメニューの拡張ができます。

## 機能

### カスタムサイドバーリンク

- traQのサイドバーに任意のリンクを追加
- 「ホームチャンネル」「チャンネル」の各セクションに配置可能
- 設定画面からリンクの追加・削除・並べ替え
- ドラッグ＆ドロップによる表示順の変更
- traQ本体のデザインに合わせた表示
- 現在開いているページに対応するリンクを選択表示

### サービスメニューの拡張

traQのサービスメニューに以下のサービスを追加します。

- traQing
- traQ gazer
- Q Bell

## インストール

1. このリポジトリをZIPでダウンロードし、展開する
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックする
5. `manifest.json` が含まれているフォルダを選択する

## 使い方

### カスタムリンクの設定

1. ChromeのツールバーからtraQuickのアイコンをクリックする
2. 設定画面で表示名・URL・配置先を入力する
3. 「追加」をクリックする
4. 必要に応じてドラッグ＆ドロップで順序を変更する

設定はChromeのローカルストレージに保存されます。

### サービスメニュー

traQを開くと、サービスメニューに追加のサービスが表示されます。

## 動作環境

- Google Chrome（Manifest V3対応）

## 注意事項

- 非公式のChrome拡張機能です。
- traQのDOM構造やCSSクラスに依存する部分があるため、traQ本体の更新によって正常に動作しなくなる可能性があります。
- 現在の実装は `https://q.trap.jp/` を対象としています。
